# Hospital Makeover Studio™
The intelligence and investment planning platform for hospital modernization.

Upload your blueprint. Discover opportunities. Simulate operations. Calculate potential returns.

## v0.1 demonstration
Open `index.html` locally in a modern browser. Synthetic data only. File previews stay in browser memory; no AI extraction, server upload, clinical advice or validated engineering simulation. Financial outputs are illustrative, not investment advice. No real facility plans or credentials in this public repository.

Planned modules: Blueprint Studio, Makeover AI, Spatial AI, HospitalSim, Investment AI, Project Portfolio. AION and AfricaCap integrations are proposed, not connected.

A Streamworld AI™ Original.
